React Native + Expo SDK 56 + Supabase grocery list app for 3–4 person households.

**Completed tickets:** T-001 through T-006
- T-001: Project scaffold + Expo Router setup
- T-002: Supabase client + auth hooks
- T-003: Database schema (migrations/20260615000000_initial_schema.sql)
- T-004: RLS policies (migrations/20260615000001_rls_policies.sql)
- T-005: Auth screens (sign-in, sign-up)
- T-006: Household creation and invite flow

**Why:** Building a household collaboration app; each ticket adds a feature layer.

**How to apply:** When working on new tickets, check docs/tasks.md for scope, run check.sh after each ticket to verify.

**Key architectural notes:**
- Route groups: `(auth)`, `(onboarding)`, `(app)` — root layout guards routing based on session + householdId
- `useHousehold` hook watches `household_members` via Supabase Realtime
- Invite tokens are hex strings (crypto.getRandomValues), 48hr expiry, single-use
- Deep links: `grocerylist://join?token=X` routes to `/(onboarding)/join.tsx`
- Pending join token saved to AsyncStorage when unauthenticated user taps invite link; replayed after login
- `expo-clipboard ~56.0.4` added for invite link copy
- `.expo/types/router.d.ts` must be manually updated when adding routes (auto-generated by expo export but tsc runs first)
